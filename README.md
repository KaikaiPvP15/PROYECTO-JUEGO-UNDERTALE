
# PROYECTO-JUEGO-UNDERTALE README 

Nuestro proyecto de programacion con el README y el codigo.
Cómo descargar y ejecutar el proyecto:
Una persona externa puede obtener el proyecto descargándolo desde el repositorio de GitHub.

-----------------------------------------------------------------------------------------------------------------

Paso 1. Descargar el proyecto

Entrar en el siguiente enlace:
[PROFE NO ME DEJA METER EL CODIGO AL REPOSITORIO PQ PESA MAS D LO QUE PUEDE SOPORTAR.]
Una vez dentro, pulsar el botón Code y seleccionar Download ZIP.
Después, descomprimir el archivo descargado en una carpeta del ordenador.

-----------------------------------------------------------------------------------------------------------------

Paso 2. Comprobar que Java está instalado

Abrir una terminal y escribir:
java -version
Si muestran una versión instalada, se puede continuar.

-----------------------------------------------------------------------------------------------------------------

Paso 3. Abrir la carpeta del proyecto

Acceder desde la terminal a la carpeta donde se encuentra el archivo Main.java.

-----------------------------------------------------------------------------------------------------------------

Paso 4. Compilar el programa

Ejecutar el siguiente comando:
javac -encoding UTF-8 Main.java
Este comando compila el código Java y genera el archivo Main.class, necesario para ejecutar la aplicación.

-----------------------------------------------------------------------------------------------------------------

Paso 5. Ejecutar el juego

Una vez compilado, introducir:
java Main
El programa se iniciará en la consola y aparecerá la pantalla principal del JUEGO.
A partir de ese momento, el usuario podrá introducir sus respuestas y jugar utilizando el teclado.

-----------------------------------------------------------------------------------------------------------------

Otra forma seria instalar el archivo y abrirlo con Intellij para ahi copiar y pegar el codigo java.
